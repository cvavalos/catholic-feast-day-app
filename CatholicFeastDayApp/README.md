# Catholic Feast Day App

A Java desktop application designed to manage and present the Catholic feast days
of each liturgical year. The application retrieves data from the CalAPI, stores it in
a SQLite database, and displays the information using a JavaFX UI.

## 

## Features

* Displays the feast day information of the selected day
* Uses a calendar to iterate between days and months
* Has a search bar to search by date in a specific format (e.g.: 2026-08-26)
* Retrieves data from the CalAPI
* Stores data locally using SQLite
* Uses JavaFX for UI design

##
